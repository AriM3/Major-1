# Major-1
Bitwise Operations interactive program

Description
This is a C program that uses a menu system to perform multiple operation on 32 bit unsigned integer using just bitwise operators.
The program displays a menu and allows for a user to select one of the following opearations from the menu. Count Leading Zeros, Rotate Right, Parity and Endian swap.
The program prompts for the user to enter a number and based on the operation selected by the user from the menu, the program performs the operation and displays the result.
